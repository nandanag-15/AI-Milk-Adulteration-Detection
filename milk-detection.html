About

AI-Powered Milk Adulteration Detection System

This project uses a trained machine-learning model to analyse the measured properties of a milk sample and predict whether it may be adulterated. This website is the front end: it collects the sample values, sends them to the backend API, and displays the response.

Sample parameters

The model uses the following 12 inputs:

  • Cells
  • QValue
  • Fat
  • Protein
  • Lactose
  • Solids
  • FFA
  • Citrate
  • FrzPoint
  • SNF
  • MUN
  • Casein

Please note

Predictions come from the connected model and depend on the quality of the input values. Use the units and ranges defined by the project dataset, and confirm important results with standard laboratory testing.
